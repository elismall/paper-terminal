Decisions you need to make

1. Market: decided

Stocks, options and crypto, all through Alpaca's free paper account. Freqtrade stays an option for automated crypto later.

2. Style: decided

Swing plays on daily bars, intraday setups, option ideas and long-term holds, all in one terminal. Free data is IEX-only, so intraday volume is partial.

3. Hosting: decided

Vercel free plan, project tb-terminal. No domain or local program needed. Next: add the Alpaca keys, then move the source to a private GitHub repo.
